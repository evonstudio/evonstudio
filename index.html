1
Step One · Discover
找到你的「饭碗知识」
⏱ 5分钟
  • ✓
    写下你做过的工作/经历（哪怕是很久以前的） 护士、老师、会计、烘焙、销售、全职妈妈都算
  • ✓
    写下你最近自己学会或解决过的事情 例：省钱购物、宝宝睡眠、Instagram 排版
  • ✓
    圈出其中一个「别人经常来问你」的话题 朋友问你的 = 你的隐藏专长
✏️ 填空练习
我曾经 做过 / 学过，
所以我懂得如何帮人解决 什么问题。
护士 Nurse
教妈妈看懂宝宝发烧信号
会计 Accountant
教家庭记账省钱法
老师 Teacher
教小孩阅读专注力方法
全职妈妈 SAHM
教碎片时间管理 + 省钱技巧
2
Step Two · Define
确定你要帮的那个人
⏱ 5分钟
  • ✓
    描述她是谁（年龄、身份、处境） 例：25-40岁、全职妈妈、想在家赚副业
  • ✓
    写下她最大的烦恼或挫折感是什么 例："不知道从哪里开始"、"没有时间"
  • ✓
    写下她希望达到的结果是什么 例：每个月多$500-$1000、在家工作自由时间
✏️ 填空练习
我帮 目标对象，
解决她 最大的烦恼，
帮她实现 她想要的结果。
3
Step Three · Package
打包成一个简单产品
⏱ 10分钟
  • ✓
    选择一个你今天就能完成的产品格式
  • ✓
    把你的知识整理成 3-5 个步骤或重点 不需要写很长，清晰 > 完美
  • ✓
    给产品起一个简单清楚的名字 例："在家妈妈接单入门指南"
  • ✓
    用 Canva 或 Word 简单排版（不需要很花哨）
📄 PDF 清单 / Checklist
📖 简单电子书（5-10页）
🗂️ 模版（Canva / Excel）
🎥 短视频教学
📋 步骤指南 How-to Guide
4
Step Four · Craft
写出一句话吸引人的文案
⏱ 5分钟
  • ✓
    套用公式写出你的一句话文案
  • ✓
    确认文案里有"谁"、"怎么做"、"结果"三个元素
  • ✓
    加上一句消除顾虑的话 例："就算完全没经验也可以"
✏️ 文案公式
我帮 谁，
用 多短时间 / 多简单的方法，
做到 什么结果，
就算 她的顾虑 也没关系。
💡 EXAMPLE
「我帮全职妈妈，用每天1小时，在家开始赚第一笔钱，就算完全没有经验也没关系。」
5
Step Five · Publish
今天就发出去！
⏱ 5分钟
  • ✓
    选好今天要发的平台 Instagram Story / Facebook / TikTok — 选你最常用的一个就好
  • ✓
    套用发帖模版写好你的帖子
  • ✓
    设定一个关键词（例："开始"、"资料"）让人回复或DM
  • ✓
    发出去！不等完美，先测试反应 🚀
✏️ 发帖模版

帮你 解决什么问题。
